# 凹曲面的预定义模型
凹曲面为一个绕工件坐标系Z轴旋转对称的表面。其沿XOZ平面的方程可以表示为如下分段函数：

## 多段曲线方程

该曲线由 5 段组成，每一段都有独立的适用区间。

---

### 1. 第一段：圆弧段

原始隐式方程为：

\[
x^2 + (z - 127.5)^2 = 127.5^2
\]

适用范围为：

\[
0 \leq x \leq 17.74
\]

因为该段取靠近 \(z=0\) 的下侧圆弧，所以写成 \(z=f(x)\) 为：

\[
z = 127.5 - \sqrt{127.5^2 - x^2}
\]

---

### 2. 第二段：斜直线段

原始方程为：

\[
z = -1.25 + \tan(8^\circ)x
\]

适用范围为：

\[
17.74 \leq x \leq 189.97
\]

因此：

\[
z = -1.25 + \tan(8^\circ)x
\]

---

### 3. 第三段：大圆弧段

原始隐式方程为：

\[
(x - 205.98)^2 + (z + 146.50)^2 = 172.5^2
\]

适用范围为：

\[
189.97 \leq x \leq 205.98
\]

该段取上侧圆弧，所以写成 \(z=f(x)\) 为：

\[
z = -146.50 + \sqrt{172.5^2 - (x - 205.98)^2}
\]

---

### 4. 第四段：水平直线段

原始方程为：

\[
z = 26
\]

适用范围为：

\[
205.98 \leq x \leq 213.90
\]

因此：

\[
z = 26
\]

---

### 5. 第五段：小圆弧段

原始隐式方程为：

\[
(x - 213.90)^2 + (z - 17)^2 = 9^2
\]

适用范围为：

\[
213.90 \leq x \leq 222.90
\]

该段取上侧圆弧，所以写成 \(z=f(x)\) 为：

\[
z = 17 + \sqrt{9^2 - (x - 213.90)^2}
\]

---

## 整体分段函数形式

\[
z=f(x)=
\begin{cases}
127.5-\sqrt{127.5^2-x^2}, 
& 0 \leq x \leq 17.74 \\[6pt]

-1.25+\tan(8^\circ)x, 
& 17.74 \leq x \leq 189.97 \\[6pt]

-146.50+\sqrt{172.5^2-(x-205.98)^2}, 
& 189.97 \leq x \leq 205.98 \\[6pt]

26, 
& 205.98 \leq x \leq 213.90 \\[6pt]

17+\sqrt{9^2-(x-213.90)^2}, 
& 213.90 \leq x \leq 222.90
\end{cases}
\]
