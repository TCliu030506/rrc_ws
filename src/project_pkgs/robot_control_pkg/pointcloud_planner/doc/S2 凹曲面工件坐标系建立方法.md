# 任务：基于 `pcl_roi_refined.pcd` 建立局部工件坐标系并转换点云

## 1. 任务背景

当前点云路径规划程序已有原始流程：

```text
点云采集
→ 点云滤波
→ 点云从相机坐标系转换到机械臂基坐标系
→ 手动粗选 ROI
→ ROI 精筛得到 pcl_roi_refined.pcd
```

现在需要在 `planning_mode == "concave_surface"` 模式下，基于已经提取出的目标凹曲面点云 `pcl_roi_refined.pcd`，建立一个局部工件坐标系，并将该点云转换到局部工件坐标系下保存。

对于原有模式：

```text
planning_mode == "plane"
planning_mode == "cylinder_preplan"
```

保持原有流程不变，不增加局部工件坐标系拟合逻辑。

## 3. 局部工件坐标系定义

设机械臂基坐标系为 (B)，局部工件坐标系为 (W)。

局部工件坐标系定义如下：

```text
O_W：
    目标凹曲面 ROI 的几何中心附近的实际曲面点。

Z_W：
    在 O_W 附近进行局部 PCA 平面拟合，取拟合平面的法向量作为 Z 轴。

X_W：
    将机械臂基坐标系 X_B 轴投影到 O_W 处局部切平面上，归一化后作为 X 轴。
    如果投影退化，则改用机械臂基坐标系 Y_B 轴投影。

Y_W：
    由右手定则得到，即 Y_W = Z_W × X_W。
```

最终构造：

```text
T_base_from_workpiece = ^B T_W
```

其中旋转矩阵的三列分别是：

```text
X_W 在基坐标系下的方向
Y_W 在基坐标系下的方向
Z_W 在基坐标系下的方向
```

## 7. 详细算法步骤

### 7.1 读取 `pcl_roi_refined.pcd`

读取机械臂基坐标系下的目标凹曲面点云：

```text
pcl_roi_refined.pcd
```

需要检查：

```text
1. 文件是否读取成功；
2. 点云是否为空；
3. 点数是否足够；
4. 是否存在 NaN 点。
```

建议阈值：

```text
ROI 点数 > 500
```

如果点数不足，返回 false，不继续拟合工件坐标系。

---

### 7.2 点云基础清理

至少执行：

```cpp
pcl::removeNaNFromPointCloud(...)
```

可选执行：

```cpp
pcl::StatisticalOutlierRemoval<pcl::PointXYZ>
```

第一版可以只做 NaN 去除。

---

### 7.3 通过全局 PCA 估计 ROI 的二维几何中心

不要直接使用三维质心作为工件坐标系原点，因为凹曲面的三维质心可能不在实际曲面上。

推荐方法：

1. 对整个 ROI 点云计算三维质心 (c^B)。
2. 对整个 ROI 点云做全局 PCA。
3. 得到三个主方向：

```text
e1：最大延展方向
e2：次大延展方向
e3：平均法向方向
```

4. 将每个点投影到 (e1-e2) 平面：

```text
u_i = (p_i - c) · e1
v_i = (p_i - c) · e2
```

5. 计算 (u) 和 (v) 的百分位范围，推荐使用 5% 和 95% 分位数，避免边缘噪声影响：

```text
u_low  = percentile(u, 5%)
u_high = percentile(u, 95%)
v_low  = percentile(v, 5%)
v_high = percentile(v, 95%)
```

6. 得到二维投影中心：

```text
u0 = (u_low + u_high) / 2
v0 = (v_low + v_high) / 2
```

7. 映射回三维空间：

```text
p_center = c + u0 * e1 + v0 * e2
```

8. 在原始 ROI 点云中寻找距离 `p_center` 最近的实际点，作为工件坐标系原点：

```text
O_W = nearest_point_to(p_center)
```

这样可以保证工件坐标系原点落在实际点云表面附近。

---

### 7.4 在原点附近拟合局部法向，确定 Z 轴

以 (O_W) 为中心搜索邻域点。

推荐优先使用半径搜索：

```text
workpiece_normal_fit_radius = 0.03 m
```

要求邻域点数：

```text
workpiece_min_normal_fit_points = 50
```

如果半径内点数不足，则退化为 KNN 搜索：

```text
workpiece_normal_fit_k = 100
```

对邻域点做局部 PCA：

1. 计算邻域质心；
2. 计算协方差矩阵；
3. 特征值分解；
4. 取最小特征值对应的特征向量作为局部平面法向：

```text
Z_W = eigenvector_min
```

---

### 7.5 统一 Z 轴方向

PCA 法向存在正负二义性，因此必须统一方向。

优先使用前面去平台时得到的平台法向 `platform_normal`：

```text
if Z_W · platform_normal < 0:
    Z_W = -Z_W
```

如果程序中暂时没有保存平台法向，则使用机械臂基坐标系 Z 轴：

```text
base_z = [0, 0, 1]
if Z_W · base_z < 0:
    Z_W = -Z_W
```

目标是保证工件坐标系 Z 轴稳定朝向工件外侧或上方，避免每次运行随机翻转。

---

### 7.6 将基坐标系 X 轴投影到局部切平面，确定 X 轴

机械臂基坐标系 X 轴：

```text
base_x = [1, 0, 0]
```

将其投影到以 (Z_W) 为法向的局部切平面上：

```text
x_proj = base_x - (base_x · Z_W) * Z_W
```

如果：

```text
norm(x_proj) >= workpiece_axis_projection_min_norm
```

则：

```text
X_W = normalize(x_proj)
```

并统一方向：

```text
if X_W · base_x < 0:
    X_W = -X_W
```

如果投影长度过小，说明 `base_x` 与 `Z_W` 近似平行，此时改用基坐标系 Y 轴：

```text
base_y = [0, 1, 0]
x_proj = base_y - (base_y · Z_W) * Z_W
X_W = normalize(x_proj)

if X_W · base_y < 0:
    X_W = -X_W
```

推荐参数：

```text
workpiece_axis_projection_min_norm = 0.1
```

---

### 7.7 根据右手定则确定 Y 轴

计算：

```text
Y_W = Z_W × X_W
Y_W = normalize(Y_W)
```

然后重新正交化 X 轴：

```text
X_W = Y_W × Z_W
X_W = normalize(X_W)
```

最终要求：

```text
X_W × Y_W = Z_W
```

---

### 7.8 构造变换矩阵

令：

```text
R_BW = [X_W  Y_W  Z_W]
```

其中三个坐标轴作为旋转矩阵的列向量。

构造：

```text
T_base_from_workpiece = ^B T_W =
[ R_BW   O_W ]
[ 0 0 0   1  ]
```

逆变换：

```text
T_workpiece_from_base = ^W T_B =
[ R_BW^T   -R_BW^T * O_W ]
[ 0 0 0          1       ]
```

保存为：

```text
T_base_from_workpiece.txt
T_workpiece_from_base.txt
```

---

### 7.9 将 ROI 点云转换到工件坐标系

对于每个基坐标系下的点：

```text
p_B
```

转换为工件坐标系下的点：

```text
p_W = R_BW^T * (p_B - O_W)
```

保存为：

```text
pcl_roi_refined_workpiece.pcd
```

转换完成后，点云应满足：

```text
1. 曲面中心点附近坐标接近 [0, 0, 0]；
2. 曲面中心处局部切平面接近工件坐标系的 X-Y 平面；
3. 曲面中心处法向接近工件坐标系 Z 轴；
4. 后续可以在工件坐标系下进行凹曲面参数分析和路径规划。
```

## 9. 坐标系质量检查

生成坐标系后，必须检查：

```text
|X_W| ≈ 1
|Y_W| ≈ 1
|Z_W| ≈ 1

X_W · Y_W ≈ 0
X_W · Z_W ≈ 0
Y_W · Z_W ≈ 0

det(R_BW) ≈ +1
```

推荐阈值：

```text
abs(X_W · Y_W) < 1e-3
abs(X_W · Z_W) < 1e-3
abs(Y_W · Z_W) < 1e-3
abs(det(R_BW) - 1.0) < 1e-3
```

如果检查不通过，应输出错误日志并返回 false，不进入后续路径规划。

## 11. 验收标准

实现完成后，应满足：

1. `plane` 和 `cylinder_preplan` 模式不受影响；
2. `concave_surface` 模式下可以读取 `pcl_roi_refined.pcd`；
3. 可以稳定拟合出局部工件坐标系；
4. 坐标系满足右手定则；
5. `det(R_BW)` 接近 +1；
6. 可以输出 `T_base_from_workpiece.txt` 和 `T_workpiece_from_base.txt`；
7. 可以输出 `pcl_roi_refined_workpiece.pcd`；
8. 转换后的点云中心区域应靠近工件坐标系原点；
9. 如果点云点数不足、邻域拟合失败或坐标系检查失败，程序应返回 false 并输出明确错误日志，而不是崩溃。
