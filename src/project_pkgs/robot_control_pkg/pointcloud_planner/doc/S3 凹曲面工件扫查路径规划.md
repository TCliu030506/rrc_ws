# 任务：基于三维球半径的凹曲面扫查路径规划实现说明

## 1. 任务目标

在现有 `pointcloudslam_cpp` 工程中新增一个面向凹曲面的路径规划模式：

```text
planning_mode == "concave_surface"
```

该模式用于在已提取出的凹曲面 ROI 上生成扫查路径。路径规划采用三维球坐标思想：以局部工件坐标系原点为中心，用三维球半径 (r) 作为由外向内的分层变量，用绕 (Z_W) 轴的角度 (\varphi) 作为环向扫查变量，形成“外圈开始、环向扫查、径向进给、逐层向中心收缩”的扫查路径。

原有模式：

```text
planning_mode == "plane"
planning_mode == "cylinder_preplan"
```

保持原流程不变。

---

## 2. 前置条件

假设前面两个模块已经完成：

### 2.1 凹曲面 ROI 提取

已从原始点云中提取出目标凹曲面 ROI，并保存：

```text
pcl_roi_refined.pcd
```

该文件中的点云默认位于机械臂基坐标系 (B) 下。

### 2.2 局部工件坐标系建立

已基于 `pcl_roi_refined.pcd` 建立局部工件坐标系 (W)，并输出：

```text
pcl_roi_refined_workpiece.pcd
T_base_from_workpiece.txt
T_workpiece_from_base.txt
```

其中：

```text
pcl_roi_refined_workpiece.pcd
```

表示目标凹曲面 ROI 在局部工件坐标系 (W) 下的点云。

```text
T_base_from_workpiece.txt
```

表示：

[
{}^B T_W
]

即工件坐标系到机械臂基坐标系的变换矩阵。

## 3. 本模块输入与输出

### 3.1 输入文件

```text
pcl_roi_refined_workpiece.pcd
T_base_from_workpiece.txt
```

### 3.2 输出文件

建议输出：

```text
path_map_concave.txt
path_map_concave_workpiece.txt
path_debug_concave.txt
```

其中：

```text
path_map_concave.txt
```

为最终给 UR5 执行的机械臂基坐标系下 TCP 位姿序列，每行格式为：

```text
x y z rx ry rz
```

其中：

```text
x y z
```

为 TCP 在机械臂基坐标系下的位置；

```text
rx ry rz
```

为旋转向量，即 axis * angle，不是 RPY 欧拉角。

```text
path_map_concave_workpiece.txt
```

保存工件坐标系下的路径调试信息，例如：

```text
x_w y_w z_w nx_w ny_w nz_w r theta phi layer_id point_id
```

```text
path_debug_concave.txt
```

保存调试日志，包括半径范围、层数、每层点数、跳过点数量、最终有效路径点数量等。

## 4. 总体流程

新增路径规划函数，例如：

```cpp
bool pcl_cloudslam::path_plan_concave();
```

建议主流程修改为：

```cpp
pcl_handle->pcl_filter();

std::string planning_mode;
pcl_handle->get_parameter("planning_mode", planning_mode);

if (planning_mode == "concave_surface") {
    pcl_handle->refine_roi_by_platform_and_normal();
    pcl_handle->fit_local_workpiece_frame_from_refined_roi();
    pcl_handle->transform_refined_roi_to_workpiece_frame();
    pcl_handle->path_plan_concave();
} else {
    pcl_handle->roi_range();
    pcl_handle->grid();
    pcl_handle->path_plan();
}
```

如果 ROI 精筛和工件坐标系拟合已经提前完成，也可以允许 `path_plan_concave()` 直接读取已有文件执行。

## 5. 数学表达

在局部工件坐标系 (W) 下，凹曲面点云中每个点为：

[
p_i^W=[x_i,y_i,z_i]^T
]

定义三维球半径：

[
r_i=\sqrt{x_i^2+y_i^2+z_i^2}
]

定义绕 (Z_W) 轴的环向角：

[
\varphi_i=\operatorname{atan2}(y_i,x_i)
]

定义径向截面内的仰角：

[
\theta_i=\operatorname{atan2}(z_i,\sqrt{x_i^2+y_i^2})
]

因此，点云可以表示为：

[
p_i^W \rightarrow (r_i,\theta_i,\varphi_i)
]

路径规划主要使用：

```text
r：由外向内的分层变量
φ：绕 Z_W 轴的环向扫查变量
θ：由局部点云估计，用于重建路径点三维位置
```

---

## 6. 路径覆盖逻辑

采用从外向内的同心层扫查：

```text
第 0 层：外圈扫查
第 1 层：向内进给一步后反向扫查
第 2 层：继续向内进给后正向扫查
……
直到中心区域
```

路径结构：

```text
layer 0: φ = 0 → 2π
layer 1: φ = 2π → 0
layer 2: φ = 0 → 2π
layer 3: φ = 2π → 0
...
```

采用正反交替扫查，减少层间空走，降低机械臂腕部连续单向绕转风险。

---

## 7. 探头覆盖区间与路径中心半径

必须区分：

```text
探头覆盖区域
探头中心路径
```

设：

```text
l：探头沿径向方向的有效覆盖长度
w：每层向内进给步距
m：外边界安全余量
r_max：ROI 外边界半径
r_c,k：第 k 层探头中心路径半径
```

建议用 ROI 点云中 (r_i) 的 95% 分位数作为外边界半径：

[
r_{\max}=\operatorname{percentile}(r_i,95%)
]

不要直接使用最大值，避免离群点影响。

第 (k) 层外边界半径：

[
r_{\text{out},k}=r_{\max}-m-kw
]

第 (k) 层覆盖范围：

[
r_{\text{out},k}-l \le r \le r_{\text{out},k}
]

第 (k) 层探头中心半径：

[
r_{c,k}=r_{\text{out},k}-\frac{l}{2}
]

即第一层探头中心不走在 (r_{\max}) 上，而是走在：

[
r_{\max}-m-\frac{l}{2}
]

这样可以避免探头外侧超出目标 ROI 边界。

如果：

[
w<l
]

则相邻层之间存在重叠：

[
overlap=l-w
]

这是推荐设置。

---

## 8. 半径层终止条件

从外向内生成：

[
r_{c,k}=r_{\max}-m-kw-\frac{l}{2}
]

当：

[
r_{c,k} \le r_{\text{end}}
]

停止生成新的环形扫查层。

推荐：

```text
r_end = w / 2
```

或者固定：

```text
r_end = 0.005 ~ 0.010 m
```

原因：靠近中心时，环向方向不稳定，继续强行环扫会导致姿态快速变化。

中心区域可选处理：

```text
方案 A：直接停止
方案 B：增加一个中心点
方案 C：增加一个小半径补扫圆
```

第一版建议采用方案 A 或 B。

---

## 9. 每层角度步长

对于第 (k) 层，理论上：

[
\varphi \in [0,2\pi]
]

角度步长不建议固定，而应根据期望空间采样间距计算：

[
\Delta\varphi_k=\frac{s_{\text{scan}}}{r_{c,k}}
]

其中：

```text
s_scan：相邻路径点的期望空间间距
```

推荐：

```text
s_scan = 0.002 ~ 0.005 m
```

同时设置角度步长上下限：

```text
delta_phi_min_deg = 0.5
delta_phi_max_deg = 5.0
```

换算为弧度后使用：

[
\Delta\varphi_k =
\operatorname{clamp}
\left(
\frac{s_{\text{scan}}}{r_{c,k}},
\Delta\varphi_{\min},
\Delta\varphi_{\max}
\right)
]

---

## 10. 路径点位置生成

对于每一层 (k)，每个角度点 (j)，目标参数为：

[
(r,\varphi)=(r_{c,k},\varphi_j)
]

需要从点云中估计该位置对应的 (\theta)，然后重建三维路径点。

### 10.1 对 ROI 点云建立参数表

对 `pcl_roi_refined_workpiece.pcd` 中每个点计算并缓存：

```cpp
struct SphericalPoint {
    Eigen::Vector3d p;   // x, y, z in workpiece frame
    double r;
    double theta;
    double phi;
};
```

其中：

```cpp
r = sqrt(x*x + y*y + z*z);
phi = atan2(y, x);
theta = atan2(z, sqrt(x*x + y*y));
```

注意：

```text
phi 需要处理 -π 到 π 与 0 到 2π 的周期问题。
```

建议统一到：

```text
[0, 2π)
```

---

### 10.2 在参数域中搜索邻域

对目标 ((r_{c,k},\varphi_j))，搜索满足：

[
|r_i-r_{c,k}|<r_{\text{fit}}
]

[
|\operatorname{wrapToPi}(\varphi_i-\varphi_j)|<\varphi_{\text{fit}}
]

的点作为邻域点。

推荐初始参数：

```text
concave_r_fit = 0.008 ~ 0.015 m
concave_phi_fit_deg = 3 ~ 8 deg
concave_min_fit_points = 8 ~ 20
```

如果邻域点不足：

```text
第一版：跳过该路径点
第二版：逐步增大 r_fit / phi_fit 后重试
```

建议第一版先跳过，同时记录跳过数量。

---

### 10.3 估计路径点的 theta

对邻域点中的 (\theta_i) 进行估计。

第一版采用简单平均：

[
\theta_{k,j}=\frac{1}{N}\sum_i\theta_i
]

更稳的版本采用加权平均：

[
\theta_{k,j}
============

\frac{\sum_i w_i\theta_i}{\sum_i w_i}
]

权重：

[
w_i=
\exp\left(
-\frac{(r_i-r)^2}{2\sigma_r^2}
-\frac{\Delta\varphi_i^2}{2\sigma_\varphi^2}
\right)
]

第一版建议实现加权平均，参数可取：

```text
sigma_r = concave_r_fit / 2
sigma_phi = concave_phi_fit / 2
```

如果加权和过小，则退化为简单平均。

---

### 10.4 由 ((r,\theta,\varphi)) 重建三维路径点

得到 (\theta_{k,j}) 后：

[
x = r\cos\theta\cos\varphi
]

[
y = r\cos\theta\sin\varphi
]

[
z = r\sin\theta
]

得到工件坐标系下路径表面点：

[
p_{\text{surface}}^W=[x,y,z]^T
]

---

## 11. 曲面法向估计

每个路径点需要曲面法向。

对路径表面点 (p_{\text{surface}}^W)，在 `pcl_roi_refined_workpiece.pcd` 中搜索邻域点：

[
|p_i^W-p_{\text{surface}}^W|<normal_fit_radius
]

推荐参数：

```text
concave_normal_fit_radius = 0.010 ~ 0.020 m
concave_min_normal_fit_points = 8 ~ 20
```

用邻域点做 PCA 平面拟合：

1. 计算邻域质心；
2. 计算协方差矩阵；
3. 特征值分解；
4. 最小特征值对应的特征向量为法向。

记为：

[
n^W
]

法向方向统一：

```text
if n.z < 0:
    n = -n
```

保证法向大致朝向 (+Z_W)。

如果邻域点不足，则跳过该路径点。

---

## 12. 扫查方向与进给方向

对于路径点 ((r,\theta,\varphi))，定义三维球径向方向：

[
e_r =
\begin{bmatrix}
\cos\theta\cos\varphi\
\cos\theta\sin\varphi\
\sin\theta
\end{bmatrix}
]

定义环向方向：

[
e_\varphi =
\begin{bmatrix}
-\sin\varphi\
\cos\varphi\
0
\end{bmatrix}
]

由于真实路径点在曲面上，需要将方向投影到局部切平面。

扫查方向：

[
t_{\text{scan}}
===============

e_\varphi-(e_\varphi\cdot n)n
]

归一化：

[
t_{\text{scan}}=\frac{t_{\text{scan}}}{|t_{\text{scan}}|}
]

径向/进给方向：

[
t_{\text{feed}}
===============

e_r-(e_r\cdot n)n
]

归一化：

[
t_{\text{feed}}=\frac{t_{\text{feed}}}{|t_{\text{feed}}|}
]

若当前层为反向扫查，则：

[
t_{\text{scan}}=-t_{\text{scan}}
]

若需要明确“向中心进给方向”，则可用：

[
-t_{\text{feed}}
]

作为层间进给方向。

需要检查：

```text
norm(t_scan) > 1e-6
norm(t_feed) > 1e-6
abs(t_scan · t_feed) 不要求严格为 0，但后续构造姿态时需要正交化
```

如果方向退化，则跳过该路径点，或使用上一有效点方向作为 fallback。

---

## 13. 探头姿态构造

根据当前需求：

```text
探头法向与凹曲面法向共线
探头长边沿三维径向方向
探头扫查运动沿环向方向
```

建议定义工具坐标系：

```text
工具 X 轴：扫查方向 t_scan
工具 Y 轴：探头长边 / 进给方向 t_feed
工具 Z 轴：探头法向方向
```

考虑实际 TCP 坐标系定义，若工具 Z 轴是从法兰指向探头接触面的方向，则通常取：

[
z_T^W=-n
]

否则可取：

[
z_T^W=n
]

第一版建议用参数控制：

```text
concave_tool_z_align = "negative_normal" 或 "positive_normal"
```

姿态构造：

[
x_T^W=t_{\text{scan}}
]

[
z_T^W=-n
]

[
y_T^W=z_T^W \times x_T^W
]

归一化 (y_T^W)，再重新正交化：

[
x_T^W=y_T^W \times z_T^W
]

最终：

[
R_{WT}=
[x_T^W \quad y_T^W \quad z_T^W]
]

如果使用已有工具安装补偿：

[
R_{WT}^{final}=R_{WT}R_{\text{mount}}
]

其中：

```text
R_mount 由 tool_mount_rx, tool_mount_ry, tool_mount_rz 生成。
```

---

## 14. 表面点到 TCP 点的转换

路径规划得到的是探头接触中心或表面参考点：

[
p_{\text{surface}}^W
]

但最终要输出 UR5 TCP 位姿。

设：

```text
surface_clearance：沿表面法向离开工件的安全距离
probe_offset：探头尖端相对 TCP 的偏移，定义在 TCP 坐标系下
```

先将位置和姿态转换到机械臂基坐标系：

[
p_{\text{surface}}^B = R_{BW}p_{\text{surface}}^W + O_W^B
]

[
n^B = R_{BW}n^W
]

[
R_{BT}=R_{BW}R_{WT}^{final}
]

TCP 位置可按现有逻辑处理：

[
p_{\text{tcp}}^B
================

p_{\text{surface}}^B
+
surface_clearance \cdot n^B
---------------------------

R_{BT} \cdot probe_offset
]

注意：

```text
probe_offset 的符号和方向必须与当前工程已有 path_plan() 中的定义保持一致。
```

最终输出：

[
P=[p_{\text{tcp},x}^B,p_{\text{tcp},y}^B,p_{\text{tcp},z}^B,rx,ry,rz]
]

其中 ([rx,ry,rz]) 是 (R_{BT}) 转换得到的连续旋转向量。

---

## 15. 姿态连续性处理

必须处理姿态连续性，否则绕圈路径中容易出现旋转向量跳变。

建议复用或参考已有逻辑：

```text
1. 将 R_BT 转换为 quaternion；
2. 若当前 quaternion 与上一帧 quaternion 点积 < 0，则取反；
3. 再转为 AngleAxis；
4. 输出 axis * angle；
5. 必要时对相邻旋转向量做 unwrap 或限幅。
```

同时建议对法向做连续性处理：

```text
if current_normal · previous_normal < 0:
    current_normal = -current_normal
```

可以增加法向平滑：

[
n_{\text{smooth}} =
\operatorname{normalize}
(
\alpha n_{\text{current}}
+
(1-\alpha)n_{\text{previous}}
)
]

参数：

```text
concave_normal_smoothing_alpha = 0.2
```

---

## 16. 层间过渡路径

每层扫查完成后，需要从：

[
r_{c,k}
]

进给到：

[
r_{c,k+1}
]

建议在当前层结束角度 (\varphi_{\text{end}}) 处插入若干过渡点。

过渡方式：

```text
固定 φ = 当前层结束角
r 从 r_c,k 线性变化到 r_c,k+1
对每个过渡 r，同样估计 theta、位置、法向和姿态
```

过渡点间距可使用：

```text
concave_feed_step = 0.002 ~ 0.005 m
```

如果第一版希望简单，也可以不单独插入过渡点，直接让下一层第一个点作为进给目标。但推荐插入过渡点，使机械臂运动更平滑。

```text
    在三维空间中拟合法向的邻域半径。

    层间进给过渡点的间距。

    控制工具 Z 轴取 +normal 还是 -normal。
```

## 19. 异常处理

必须处理以下异常：

```text
1. pcl_roi_refined_workpiece.pcd 读取失败；
2. 点云点数太少；
3. T_base_from_workpiece.txt 读取失败；
4. r_max 计算异常；
5. concave_radial_step <= 0；
6. concave_probe_radial_length <= 0；
7. 某路径点邻域点数不足；
8. 法向拟合失败；
9. 姿态矩阵 det(R) 不接近 +1；
10. 最终有效路径点数量太少。
```

处理方式：

```text
文件或参数错误：直接返回 false，不生成路径；
单个路径点失败：跳过该点，并记录 skipped_point_count；
若某一层有效点太少：跳过该层；
若最终路径点数量低于阈值：返回 false。
```

建议阈值：

```text

min_valid_points_per_layer = 8
```

## 23. 方法总结

本方案在局部工件坐标系下，将凹曲面点云表示为 ((r,\theta,\varphi)) 形式，其中 (r) 为点到工件坐标系原点的三维球半径，(\varphi) 为绕 (Z_W) 轴的环向角度，(\theta) 为径向截面内的仰角。路径规划时，以 (r) 作为由外向内的分层变量，以 (\varphi) 作为环向扫查变量；每一层根据探头径向覆盖长度 (l)、径向进给步距 (w) 和边界安全余量 (m) 确定探头中心半径，沿 (\varphi) 方向完成一圈扫查后向内收缩一层。每个路径点通过 ((r,\varphi)) 邻域点云估计 (\theta)，重建三维位置，并通过局部 PCA 拟合获得曲面法向。最终使探头法向与曲面法向共线，探头长边沿三维径向方向，扫查运动沿环向方向，从而形成由外缘向中心逐层覆盖的凹曲面扫查路径。
