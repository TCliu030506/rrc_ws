基于工具坐标系导纳控制的机器人恒定接触力曲面扫查策略
论文方法章节 / 工程操作文档整理版
1. 策略目标与基本思想
本文档给出一种面向机器人辅助超声曲面扫查的恒定接触力控制策略。该策略以深度相机规划得到的粗扫查路径作为几何先验，通过低速接触搜索建立初始接触并估计法向偏置，然后在接触扫查阶段采用工具坐标系下的六自由度导纳控制器，根据实际接触力/力矩与期望接触力/力矩之间的误差实时生成柔顺偏移位姿，并将该偏移叠加到名义扫查轨迹上，最终得到发送给机械臂的目标位姿。
该策略的核心逻辑不是直接将视觉粗路径作为最终执行轨迹，而是将其作为扫查方向、姿态初值和几何先验；接触建立后的法向位置和局部贴合状态由力反馈实时修正。整体流程可概括为：
视觉粗路径 P0 -> 接触搜索得到法向偏置 delta_c -> 接触扫查路径 P2 -> 导纳补偿后执行位姿 Pcmd
2. 位姿、路径与坐标系定义
机械臂工具目标位姿采用 UR5 常用的六维位姿向量表示：
P = [x, y, z, rx, ry, rz]^T = [p^T, r^T]^T in R^6
其中，p=[x,y,z]^T 表示工具 TCP 在机器人基坐标系下的位置，r=[rx,ry,rz]^T 表示工具姿态的旋转向量。由旋转向量 r 可通过 Rodrigues 公式得到对应旋转矩阵：
R = RotVecToMat(r) in SO(3)
设深度相机和路径规划模块输出的粗扫查路径为：
Pset0 = {P0[i]}_{i=1}^{N},    P0[i] = [p0[i]^T, r0[i]^T]^T
工具坐标系下的 Z 轴单位向量定义为 e_z=[0,0,1]^T。第 i 个路径点处，工具 Z 轴在机器人基坐标系下的方向为：
z0[i] = R0[i] e_z,    R0[i] = RotVecToMat(r0[i])
根据探头安装方向，定义接近扫查面的单位方向为：
a_i = s_z R0[i] e_z,    s_z in {+1, -1}
其中 s_z 用于描述探头沿工具 +Z 方向或 -Z 方向接近扫查面。工程实现中应统一符号约定，使 a_i 始终表示“探头压向扫查面”的方向。
3. 总体状态机
该策略采用分阶段状态机实现，避免将“远距离寻找接触面”和“接触后维持恒定接触力”混合在一个导纳控制器中。导纳控制器主要用于接触建立后的柔顺调节，不应单独承担从远离表面的状态自动寻找接触面的任务。
阶段	名称	主要目标	核心输出/切换条件
阶段 1	接近阶段	工具运动至粗扫查路径起点 P0[1]	到达位置与姿态误差阈值
阶段 2	预接触阶段	沿工具接近方向低速前进并检测接触力	f_n >= f01，记录 delta_c
阶段 3	恒定接触力扫查阶段	基于工具坐标系导纳控制生成柔顺偏移并叠加到名义路径	持续输出 Pcmd
阶段 4	撤离阶段	扫查完成后沿远离扫查面的方向撤离	工具脱离工件/人体表面
4. 阶段 1：接近阶段
机械臂首先运动至粗扫查路径起点 P0[1]。该阶段采用常规位姿控制，目标位姿为：
Pcmd(t) -> P0[1] = [p0[1]^T, r0[1]^T]^T
为降低接近终点时的冲击和超调，可采用由快到慢的速度规划。设当前位置为 p(t)，目标位置为 p0[1]，距离误差为：
d(t) = ||p0[1] - p(t)||
可选用如下速度规划函数：
v(t) = v_min + (v_max - v_min) * sat(d(t)/d_slow, 0, 1)
当远离目标点时 v(t) 接近 v_max；当接近目标点时 v(t) 逐渐降低至 v_min。阶段切换条件可写为：
||p(t)-p0[1]|| < epsilon_p,    ||Log(R0[1]^T R(t))|| < epsilon_R
其中 Log(.) 表示旋转矩阵到旋转向量的映射。满足上述条件后进入预接触阶段。
5. 阶段 2：预接触阶段
预接触阶段的目标是在不依赖导纳控制大范围积分的情况下，安全、缓慢、可靠地建立初始接触。机械臂从粗扫查路径起点沿当前工具接近方向前进，姿态保持不变。
5.1 预接触运动律
预接触阶段的位置命令为：
p_cmd(t) = p0[1] + s(t) a_1
姿态命令保持为：
r_cmd(t) = r0[1]
因此六维目标位姿为：
Pcmd(t) = [(p0[1]+s(t)a_1)^T, r0[1]^T]^T
其中 s(t) 是沿接近方向的搜索距离，a_1=s_z R0[1] e_z，且：
dot{s}(t) = v_s(t)
5.2 接触力检测与速度调节
设力传感器经重力补偿、零偏补偿和坐标变换后得到工具坐标系下的外部广义力：
W_ext_T(t) = [F_ext_T(t)^T, M_ext_T(t)^T]^T
若接触方向对应工具 Z 轴，则法向接触力可定义为：
f_n(t) = s_f * F_z,ext_T(t),    s_f in {+1, -1}
其中 s_f 用于统一力传感器符号，使 f_n(t)>0 表示压紧力增大。若外部力最初在基坐标系下表示，则需先转换至工具坐标系：
F_ext_T = R(t)^T F_ext_B,    M_ext_T = R(t)^T M_ext_B
预接触阶段速度可设计为随外部力增大而减小：
v_s(t)=v_min+(v_max-v_min)*sat(1-f_n(t)/f01, 0, 1)
当 f_n(t)≈0 时，搜索速度接近 v_max；当 f_n(t) 接近初始接触阈值 f01 时，搜索速度降低至 v_min，从而降低接触瞬间冲击。接触判据为：
f_n(t_c) >= f01
接触建立时记录接触搜索距离：
delta_c = s(t_c)
5.3 接触扫查路径构造
利用接触搜索得到的法向偏置 delta_c，对粗扫查路径进行整体接触修正。对第 i 个路径点：
a_i = s_z RotVecToMat(r0[i]) e_z
p2[i] = p0[i] + delta_c a_i
r2[i] = r0[i]
P2[i] = [p2[i]^T, r2[i]^T]^T
该步骤相当于通过起点处的接触搜索，对视觉粗路径进行一次沿工具接近方向的接触标定。若视觉路径整体形状准确，主要误差来自整体高度偏差、手眼标定误差或 TCP 标定误差，则单一 delta_c 可推广到整条路径。若局部几何误差明显，则后续可扩展为局部偏置 delta_c[i] 或在接触丢失时重新搜索。
6. 阶段 3：恒定接触力导纳扫查阶段
建立初始接触后，控制系统进入恒定接触力扫查阶段。该阶段以接触扫查路径 P2 作为名义轨迹，同时在工具坐标系下运行六自由度导纳控制器，根据实际接触广义力与期望接触广义力之间的误差生成柔顺偏移位姿。
6.1 工具坐标系下的导纳模型
定义工具坐标系下的实际外部广义力为：
W_ext_T = [Fx, Fy, Fz, Mx, My, Mz]^T
定义期望外部广义力为：
W_des_T = [Fx_d, Fy_d, Fz_d, Mx_d, My_d, Mz_d]^T
例如仅要求工具 Z 向保持目标压紧力、其余方向不主动施加力/力矩时，可取：
W_des_T = [0, 0, Fz_d, 0, 0, 0]^T
广义力误差定义为：
e_W_T(t) = W_des_T - W_ext_T(t)
六自由度导纳模型为：
M_a ddot(DeltaP_a_T) + B_a dot(DeltaP_a_T) + K_a DeltaP_a_T = e_W_T
其中，导纳输出为工具坐标系下的六维柔顺偏移位姿：
DeltaP_a_T = [Delta_x, Delta_y, Delta_z, Delta_rx, Delta_ry, Delta_rz]^T
虚拟质量、虚拟阻尼和虚拟刚度矩阵通常取对角矩阵：
M_a = diag(m_x, m_y, m_z, j_x, j_y, j_z)
B_a = diag(b_x, b_y, b_z, d_x, d_y, d_z)
K_a = diag(k_x, k_y, k_z, k_rx, k_ry, k_rz)
通过调节不同自由度上的参数，可实现不同方向的柔顺性分配。例如，工具 Z 向设置较高柔顺性以调节压紧力；工具 X/Y 向设置较低柔顺性以保持切向扫查路径；绕工具 X/Y 方向可设置适当柔顺以提高探头贴合能力；绕工具 Z 方向通常设置较高刚度以保持扫查方向稳定。
6.2 导纳输出的离散计算
设导纳控制器的计算频率为 f_a，对应周期为 Delta_ta=1/f_a。在第 k 个导纳计算周期，力误差为：
e_W_T,k = W_des_T - W_ext_T,k
由导纳方程计算柔顺加速度：
ddot(DeltaP_a_T,k) = M_a^{-1} [ e_W_T,k - B_a dot(DeltaP_a_T,k) - K_a DeltaP_a_T,k ]
通过离散积分得到柔顺速度和柔顺偏移位姿：
dot(DeltaP_a_T,k+1) = dot(DeltaP_a_T,k) + ddot(DeltaP_a_T,k) Delta_ta
DeltaP_a_T,k+1 = DeltaP_a_T,k + dot(DeltaP_a_T,k+1) Delta_ta
因此，导纳控制器输出的不是机械臂最终目标位姿，而是相对于名义路径、并定义在工具坐标系下的六维柔顺偏移位姿。
6.3 工具坐标系柔顺偏移与名义路径的叠加
由于名义路径 P2(t) 表示在机器人基坐标系下，而导纳输出 DeltaP_a_T(t) 表示在工具坐标系下，因此不能直接进行六维向量相加，而应分别处理位置和姿态。
设当前时刻由路径插值得到名义接触扫查位姿：
P2(t) = [p2(t)^T, r2(t)^T]^T
R2(t) = RotVecToMat(r2(t))
位置补偿部分为：
p_cmd(t) = p2(t) + R2(t) Delta_p_a_T(t)
姿态补偿部分为：
r_cmd(t) = MatToRotVec( R2(t) RotVecToMat(Delta_r_a_T(t)) )
最终发送给机械臂的六维目标位姿为：
Pcmd(t) = [p_cmd(t)^T, r_cmd(t)^T]^T
上述表达中，姿态增量右乘到名义姿态上，表示柔顺姿态偏移是在当前工具坐标系下定义的。
6.4 导纳计算频率与机械臂目标位姿发送频率
恒力扫查阶段需要区分两个频率：导纳控制器计算频率 f_a 与机械臂目标位姿发送频率 f_c。
频率关系	含义	工程建议
f_a = f_c	每次读取力、更新导纳、叠加位姿并发送一次目标位姿。	最推荐的初始实现，逻辑清晰且同步性好。
f_a > f_c	导纳在两个机械臂发送周期之间更新多次，发送时取最新柔顺偏移。	可提高力反馈计算精度，但实际运动仍受 f_c 限制。
f_a < f_c	多个机械臂发送周期复用同一个导纳输出。	通常不推荐，会降低力控响应速度并增加力波动。
在工程实现中，若 UR5 目标位姿以 f_c 频率发送，则每个发送时刻 t_j 应根据当前路径进度插值得到 P2(t_j)，同时取当前最新导纳输出 DeltaP_a_T(t_j)，计算 Pcmd(t_j) 后发送至机械臂。推荐初始实现采用 f_a=f_c，使每个控制周期完整执行“力测量—导纳更新—路径插值—柔顺叠加—位姿发送”的闭环流程。
Pcmd,j = P2(t_j) plus DeltaP_a_T(t_j)
其中 plus 表示按照位置旋转转换关系进行的位姿叠加，而不是简单的六维向量相加。
6.5 实时控制循环
恒力扫查阶段的实时控制循环可按如下步骤实现：
1. 根据扫查速度和路径进度插值得到当前名义接触扫查位姿 P2,k=[p2,k^T,r2,k^T]^T，并计算 R2,k=RotVecToMat(r2,k)。
2. 读取六维力传感器数据，完成零偏补偿、重力补偿和坐标变换，得到工具坐标系下的 W_ext_T,k。
3. 计算广义力误差 e_W_T,k=W_des_T-W_ext_T,k。
4. 根据六维导纳模型计算 ddot(DeltaP_a_T,k)，并积分得到 dot(DeltaP_a_T,k+1) 和 DeltaP_a_T,k+1。
5. 对导纳输出的位置、姿态、速度和加速度补偿进行限幅。
6. 将工具坐标系下的柔顺偏移 DeltaP_a_T,k+1 叠加到基坐标系下的名义位姿 P2,k，得到 Pcmd,k。
7. 以控制频率 f_c 将 Pcmd,k=[xcmd,ycmd,zcmd,rxcmd,rycmd,rzcmd]^T 发送给机械臂位姿控制模块。
7. 阶段 4：撤离阶段
扫查完成后，停止路径参数推进并退出导纳控制模式。设最终扫查位姿为 Pcmd,N=[pcmd,N^T, rcmd,N^T]^T。定义撤离方向为远离扫查面的方向 r_ret，可根据最后一个路径点的接近方向取：
r_ret = -a_N
撤离目标位置为：
p_ret = p_cmd,N + h_ret r_ret
其中 h_ret 为撤离距离。撤离目标位姿为：
P_ret = [p_ret^T, r_cmd,N^T]^T
机械臂运动至 P_ret 后完成一次扫查任务。
8. 安全约束与异常处理
为了保证工程实现的稳定性和安全性，需要在接近、预接触和恒力扫查阶段设置必要的限幅与异常处理逻辑。
8.1 预接触最大搜索距离
s(t) <= s_max
若 s(t)>s_max 且 f_n(t)<f01，说明未找到接触面，应停止搜索并重新进行视觉定位或人工检查。
8.2 最大安全接触力
f_n(t) <= f_max
若 f_n(t)>f_max，应立即停止当前运动，必要时沿撤离方向回退。
8.3 导纳补偿限幅
|Delta_x_j| <= Delta_x_j,max,    |Delta_r_j| <= Delta_r_j,max
|dot(Delta_x_j)| <= dot(Delta_x_j)_max,    |dot(Delta_r_j)| <= dot(Delta_r_j)_max
限幅的目的在于避免未接触或力误差持续存在时导纳输出过度累积，并避免接触瞬间产生过大的位置或姿态突变。
8.4 接触丢失判断
f_n(t)<f_lost  且持续时间 T>T_lost
若满足上述条件，则认为接触丢失。此时应暂停切向扫查，保持或缓慢回退姿态，并重新进入预接触搜索阶段，或重新进行局部路径规划。
9. 工程实现要点
第一，粗扫查路径 P0 主要提供曲面几何先验、扫查方向和姿态初值，不应直接作为最终接触轨迹。接触路径 P2 由接触搜索获得的法向偏置 delta_c 修正得到，最终执行路径 Pcmd 则由 P2 与导纳柔顺偏移共同决定。
第二，导纳控制器应在工具坐标系下计算，使柔顺方向与探头物理方向一致。例如工具 Z 向对应探头法向压紧方向，绕工具 X/Y 的姿态柔顺对应探头贴合调整。
第三，导纳输出 DeltaP_a_T 不能直接与基坐标系下的六维位姿向量相加。位置补偿需要通过当前名义姿态 R2 转换到基坐标系；姿态补偿需要以增量旋转形式右乘到名义姿态上。
第四，建议初期采用 f_a=f_c 的同步控制结构。若后续力传感器频率较高，可提高导纳计算频率 f_a，但机械臂实际位姿更新仍受 f_c 限制，必须对最终发送位姿进行速度和加速度约束。
第五，若只需实现基本恒定压紧力控制，可先仅开放工具 Z 向导纳柔顺，其余方向设置较高刚度；待系统稳定后，再逐步开放绕工具 X/Y 的姿态柔顺，以提高探头与曲面的贴合能力。
10. 方法总结
本文档整理的恒定接触力曲面扫查策略可以用以下核心公式概括：
P0[i] = [p0[i]^T, r0[i]^T]^T
a_i = s_z RotVecToMat(r0[i]) e_z
p2[i] = p0[i] + delta_c a_i,    P2[i] = [p2[i]^T, r0[i]^T]^T
M_a ddot(DeltaP_a_T) + B_a dot(DeltaP_a_T) + K_a DeltaP_a_T = W_des_T - W_ext_T
p_cmd = p2 + R2 Delta_p_a_T
r_cmd = MatToRotVec(R2 RotVecToMat(Delta_r_a_T))
Pcmd = [p_cmd^T, r_cmd^T]^T
该策略工程上可实现、逻辑上完整，并明确区分了视觉粗定位、接触建立、接触路径修正、导纳恒力控制和撤离等环节。相较于简单的“粗路径 + 导纳补偿”结构，该流程能够避免粗路径离扫查面过远时导纳控制无法建立接触的问题，也避免导纳输出在未接触状态下无约束累积。
